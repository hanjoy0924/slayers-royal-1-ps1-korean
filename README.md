## 적용 전 준비

- 패치 대상인 PS1 일본어판 원본 게임 파일을 직접 준비해 주세요.
- 원본 파일과 기존 메모리 카드 세이브를 먼저 백업해 주세요.
- 배포 버전에 동봉된 설명에서 원본 조건과 적용 순서를 확인해 주세요.
- 버전을 바꾸어 문제가 생겼다면, 이전 버전의 세이브 스테이트 사용 여부도 제보에 적어 주세요.

1. `SlayersRoyal1-Korean-Patch-1.0.exe`를 실행합니다.
2. 본인이 보유한 PS1 일본판 원본 디스크 이미지를 선택합니다.
3. 새 BIN/CUE 생성 방식으로 패치를 적용합니다.
4. 생성된 CUE로 게임을 실행합니다.

Windows .NET Framework 4.5 이상이 필요합니다. 동봉 CHD 변환기는 Windows x64용이며, 출력 형식은 BIN/CUE입니다.
